# MACGYVER CodeRed 

Projeto  desenvolvido para a disciplina de Sistema Embarcados. 
Consiste em um jogo no Arduino Uno inspirado na dinâmica de desarmamento de bomba.

---

##  Tecnologias e Periféricos Utilizados
* **Microcontrolador:** ATmega328P (Arduino Uno)
* **Display LCD 16x2 I2C:** Endereço `0x20` 
  * Potenciômetros 1 e 2 
  * Sensor de Luz LDR em divisor de tensão com resistor de 1k 
  * Sensor de Temperatura TMP36 
  * Botão Start 
  * Botões de Ação 1 a 4
  * Sensor de Inclinação
  * Sensor Ultrassônico de 3 pinos
  * Servomotor indicador de progresso (D9)
  * Buzzer
  * LEDs: Verde , Amarelo e Vermelho
